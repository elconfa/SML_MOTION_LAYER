   f_GetState — Extracts the functional-state base from a combined state
   SML v5 — Level A (new)

   eCombined = functional_state + E_PROGRESS
   Returns functional_state (a multiple of PROGRESS_SPAN).
   In Level B the return type will become a dedicated enum
   (e.g. E_SML_AXIS_STATE).

   Level B groundwork: not used by the Level A projection.
   ============================================================ *)

FUNCTION f_GetState : DINT
VAR_INPUT
    eCombined : DINT;
END_VAR

f_GetState := (eCombined / GVL_SML_CONST.PROGRESS_SPAN) * GVL_SML_CONST.PROGRESS_SPAN;
